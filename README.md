# 家用能源管理系统

Home Assistant 加载项，用于逆变器、蓄电池和大功率家用设备的分级减载与自动恢复。

> 当前版本：0.5.13 · Web 端口：1569 · 适用于 HAOS

## 功能

- 监测逆变器总负载、电池放电、太阳能和充电桩功率。
- 逆变器功率与电池放电功率采用“或”关系：任一路超过阈值，就按 3 级 → 2 级 → 1 级减载；0 级永不自动切断。
- 同一级优先关闭当前功率最大的设备。
- 自动恢复按 1 级 → 2 级 → 3 级逐台执行，包括手动关闭的已启用设备。
- 待恢复设备显示当前功率、恢复阈值、等待时间和具体阻塞原因。
- 电池实体当前值为有效数字时，0 W 也是有效读数，不受报告年龄设置影响。
- 支持闲时充电桩、时间窗口、光伏预测、配置备份恢复、HA Ingress 和手机页面。

## 安装

1. 下载发布页中的 home_energy_manager_HAOS_v*.zip。
2. 解压后，将 home_energy_manager 文件夹放入 Home Assistant 本地加载项目录。文件夹内必须直接包含 config.yaml、Dockerfile、Python 文件和 web 文件夹。
3. 在“设置 → 加载项 → 加载项商店”刷新本地加载项并安装。
4. 在加载项配置中设置至少 8 位的 web_password。
5. 从 HA 左侧“家用能源管理系统”进入，或访问 http://HA_IP:1569。直连用户名为 admin；HA Ingress 不需要再次输入网页密码。

已有旧版本时，请覆盖源代码并执行更新或重新构建；只重启旧容器不会替换镜像文件。

## 初次配置

在页面底部点击“管理配置”：

1. 填写逆变器总负载功率实体、电池输出功率实体和逆变器额定功率。
2. 选择电池放电方向，程序会把放电功率转换为正值。
3. 设置 1、2、3 级逆变器和电池切断阈值、恢复阈值。
4. 添加设备，填写开关实体、功率实体、等级和启用状态。
5. 先开启自动控制并保持模拟模式，确认无误后再关闭模拟模式。
6. 需要自动恢复时，开启“自动恢复供电”，设置恢复持续时间、最短断电时间和逐台恢复间隔。

## 恢复规则

恢复阈值直接比较当前功率。例如 3 级恢复值为逆变器 5000 W、电池 4000 W，必须同时满足逆变器 < 5000 W 且电池放电 < 4000 W；等于阈值仍等待。

普通设备最大功率只用于页面比例显示，不会叠加到当前功率上阻止恢复。设备仍需处于关闭状态，最短断电和逐台间隔已到，逆变器报告有效且未过期，电池实体当前值有效，并且没有正在处理的减载任务。条件不满足时页面会列出具体原因，满足后开始稳定倒计时。

电池实体为 0 W 时仍有效。只有实体不可用、unknown、缺失或无法解析为功率数值时，才暂停依赖电池的恢复判断。每次恢复一台设备后重新读取状态，再判断下一台。

## 充电桩

充电桩始终低于家庭设备优先级。电池放电超过设置值、家庭设备触发保护或逆变器达到额定功率时，优先关闭充电桩。启动规则支持闲时功率、时间窗口、光伏预测及组合条件。

## 备份与恢复

在“管理配置 → 配置备份与恢复”下载 JSON 备份。备份包含实体、设备、阈值和运行参数，不包含网页密码、HA 令牌、历史读数或设备开关状态。导入前会校验格式，恢复前会保存当前配置；恢复成功后自动控制关闭、模拟模式开启。

## 故障排查

- 页面 404：确认镜像已重新构建，检查日志中是否有 web/index.html 或 web/config.html 缺失提示。
- 功率不可用：检查实体 ID、W/kW 单位和逆变器报告年龄；电池 0 W 不属于无效状态。
- 设备不恢复：查看待恢复设备框的具体原因，检查自动恢复、自动控制、模拟模式、阈值和等待时间。
- 安装失败且没有加载项日志：查看“设置 → 系统 → 日志 → Supervisor”。

## 安全与开发

软件控制不能替代逆变器硬件过载保护，请先使用模拟模式验证并保留硬件保护余量。

测试命令：

    python -m unittest discover -s tests -v
    python -m py_compile app.py core.py settings.py telemetry.py backup.py

本项目尚未在所有 HAOS、逆变器和智能插座型号上进行真实联动测试。
